## Testing
Github Actions - for continuous integration
Jest - for unit, integration backend testing
Supertest - for e2e backend testing
Jasmine i Karma - for unit testing Angular frontend
Cypres - for e2e frontend testing
Lambdatest - for cross-browser testing
Apache jmeter - for performance testing
OWASP Zap - for security testing
Pa11y - for accessability testing

Test driven development was used to realize both the backend and frontend of this web application.
